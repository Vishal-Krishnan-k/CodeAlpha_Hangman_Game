Hangman Game

Description

This is a simple text-based Hangman game developed in Python as part of the CodeAlpha Python Programming Internship.

The program randomly selects a word from a predefined list, and the player must guess the word one letter at a time. The player has a maximum of six incorrect guesses to complete the game.

Features

- Random word selection
- Predefined list of words
- Maximum of 6 incorrect guesses
- Input validation
- Displays guessed letters
- Win/Lose messages
- Beginner-friendly Python code

Technologies Used

- Python 3
- random module

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

python hangman.py
